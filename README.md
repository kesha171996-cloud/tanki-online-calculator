# Калькулятор прокачки Tanki Online — SW_Kesha

Это браузерная версия твоего калькулятора. В ней сохранены расчётные таблицы и основная логика из Python-программы. Сайт работает на HTML, CSS и JavaScript: отдельный Python-сервер не нужен.

## Что перенесено

- Все 62 позиции: 17 пушек, 11 корпусов, 7 гранат, 19 модулей и 8 дронов.
- Таблицы стоимости прокачки из исходного Python-кода.
- Ползунки «Сейчас» и «Хочу»; целевой уровень не может быть ниже текущего.
- Общая скидка 0–50% и персональная скидка 0–100% для каждой позиции.
- Подсчёт цены, экономии и общей суммы. Скидка и округление применяются отдельно к каждой позиции — как в Python-версии.
- Пять вариантов оформления.
- 54 изображения из исходной папки `images`.
- Сохранение списка в браузере каждого посетителя, а также импорт/экспорт настроек JSON.
- Загрузка собственного фото к предмету в текущем сеансе браузера.

## Как открыть у себя

Распакуй архив и дважды нажми `index.html`. Калькулятор откроется в браузере. Для работы не нужны Python, установка библиотек или регистрация.

## Как получить бесплатную ссылку для друзей через GitHub Pages

Нужен GitHub-аккаунт. Для бесплатной публикации сайт должен находиться в публичном репозитории GitHub Free.

1. Открой <https://github.com/new>.
2. В поле **Repository name** введи, например, `tanki-online-calculator`.
3. Выбери **Public** и нажми **Create repository**.
4. Открой созданный репозиторий и выбери **Add file → Upload files**.
5. Перетащи в окно загрузки всё содержимое распакованной папки сайта: файлы `index.html`, `app.js`, `data.js`, `image_map.js`, `initial_state.js`, `styles.css`, `.nojekyll`, `README.md` и папку `images` со всеми изображениями. Важно: `index.html` должен лежать прямо в корне репозитория, а папка `images` — рядом с ним.
6. Нажми **Commit changes**.
7. В репозитории открой **Settings → Pages**.
8. В блоке **Build and deployment** в поле **Source** выбери **Deploy from a branch**.
9. В поле **Branch** выбери `main`, а папку — `/(root)`, затем нажми **Save**.
10. После публикации GitHub покажет ссылку примерно такого вида: `https://ТВОЙ-ЛОГИН.github.io/tanki-online-calculator/`. Эту ссылку можно отправлять друзьям. Посетителям не нужен аккаунт GitHub.

Официальная инструкция GitHub: <https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site>.
Инструкция по выбору ветки и папки публикации: <https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site>.

## Как работают настройки

У каждого человека собственное хранилище в его браузере (`localStorage`). Изменения одного посетителя не меняют настройки другого. Чтобы перенести свой список на другое устройство, нажми **Сохранить настройки**, а на другом устройстве — **Загрузить настройки**.

Собственные фотографии посетителя существуют только в открытом сеансе и не отправляются на сервер. В исходном архиве индивидуальные фотографии резистов находились в отдельной папке на компьютере автора, которой в ZIP не было; для резистов используется общее изображение «Любой резист.png», пока пользователь не загрузит своё фото.

## Важно о публичности

GitHub Pages публикует содержимое репозитория в интернете. Не загружай туда личные данные, пароли, токены или приватные файлы. GitHub Pages доступен бесплатно для публичных репозиториев с GitHub Free. Сервис предназначен для статических сайтов, поэтому здесь расчёты выполняются прямо в браузере — Python-сервер и платный хостинг не нужны.
