КАЛЬКУЛЯТОР ПРОКАЧКИ TANKI ONLINE — SW_KESHA

1. Чтобы проверить калькулятор на своём компьютере, распакуй архив и открой index.html.
2. Чтобы получить публичную ссылку, создай публичный репозиторий на https://github.com/new.
3. Загрузить нужно ВСЁ содержимое этой папки, включая папку images. Файл index.html должен быть в корне репозитория.
4. В репозитории открой Settings → Pages.
5. Source: Deploy from a branch.
6. Branch: main; Folder: /(root); нажми Save.
7. GitHub опубликует сайт и покажет адрес формата https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/.
8. Отправь этот адрес друзьям. Им не нужно ничего устанавливать или скачивать.

ВНИМАНИЕ:
- Репозиторий должен быть публичным, иначе бесплатный GitHub Pages не подойдёт.
- У каждого посетителя свои настройки в его браузере.
- Настройки можно скачать в JSON и перенести на другое устройство.
- Свои фотографии отображаются только в текущем сеансе браузера.
- Не загружай в публичный репозиторий личные данные и пароли.

Подробная инструкция находится в README.md.
